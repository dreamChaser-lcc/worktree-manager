# Spec Delta

## Purpose

提供浏览器可访问的本地 Web 控制台，把 worktree 管理的全部能力（目录选择、分支选择、依赖策略配置、任务进度）以可视化交互呈现，服务仅监听本机回环地址。

## ADDED Requirements

### Requirement: 服务仅监听本机回环地址

控制台服务 SHALL 仅监听 127.0.0.1，拒绝来自非本机的访问。

#### Scenario: 本机访问可用

- **WHEN** 用户在本机浏览器打开服务地址
- **THEN** 页面正常加载并可执行全部操作

#### Scenario: 非本机访问不可用

- **WHEN** 局域网内其他机器尝试访问该服务端口
- **THEN** 连接被拒绝，服务不响应

### Requirement: 目录浏览选择

界面 SHALL 提供目录浏览选择器，供用户选择主仓库目录与 worktree 目标路径。选择器 SHALL 展示目录树（含盘符/驱动器根），并可实时校验所选目录是否为 git 仓库。

#### Scenario: 浏览并选择目录

- **WHEN** 用户在选择器中逐级展开并选中某个目录
- **THEN** 表单填入该目录绝对路径

#### Scenario: 实时校验 git 仓库

- **WHEN** 用户选完主仓库目录
- **THEN** 界面立即反馈该目录是否为有效 git 仓库

### Requirement: 分支选择与占用标注

创建表单 SHALL 支持两种分支模式（已有分支下拉选择 / 新建分支输入），分支下拉 SHALL 展示各分支及其被 worktree 占用状态，被占用分支标注占用位置且不可选中。

#### Scenario: 分支下拉展示占用状态

- **WHEN** 用户选择主仓库后展开分支下拉
- **THEN** 列表展示各分支，被其他 worktree 签出的分支带有占用标注且无法选中

#### Scenario: 新建分支模式

- **WHEN** 用户切换到"新建分支"并输入分支名
- **THEN** 界面提供起点 ref 选择（默认当前 HEAD）

### Requirement: 长任务日志流

依赖安装等长耗时操作 SHALL 以异步任务执行，界面 SHALL 通过服务端推送（SSE）实时展示任务输出日志，并呈现任务最终状态（成功/失败）。

#### Scenario: 实时查看安装日志

- **WHEN** 独立安装任务执行中且用户停留在任务详情
- **THEN** 日志区域持续滚动输出最新内容，无需手动刷新

#### Scenario: 任务失败可见

- **WHEN** 安装命令执行失败退出
- **THEN** 界面标记任务失败并保留完整日志供排查

### Requirement: 创建后可选动作

创建流程 SHALL 提供两个可选后置动作，由用户勾选：

1. 复制被忽略文件：将白名单内（如 `.env`、`.env.local` 等，可配置）的未跟踪文件从主仓库复制到新 worktree
2. 打开编辑器：使用可配置的编辑器命令（默认 `code`）打开新 worktree 目录

#### Scenario: 复制忽略文件

- **WHEN** 用户勾选复制忽略文件且主仓库存在白名单文件
- **THEN** 创建完成后这些文件出现在 worktree 目录中

#### Scenario: 白名单文件不存在时静默跳过

- **WHEN** 主仓库不存在任何白名单文件
- **THEN** 该步骤跳过且不影响创建结果

#### Scenario: 打开编辑器

- **WHEN** 用户勾选打开编辑器且创建成功
- **THEN** 系统以配置的编辑器命令打开新 worktree 目录
